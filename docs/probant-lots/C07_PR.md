- **Connexion locale** par code à usage unique (`/api/auth/local`) → session ordinaire émise par `probant-local:<profil>` ; rôles et type de relecture décidés par le serveur.
- **Type de relecture** (`distinct_identity` / `personal` / `simulated_second_identity`) : l'approbation de son propre travail n'est admise qu'en relecture personnelle nommée, enregistrée et affichée comme telle (écrans, synthèses, exports) ; la seconde identité synthétique reste une simulation ; OIDC inchangé.

- **Sauvegarde cohérente** (`pg_export_snapshot` + `pg_dump --snapshot` + manifeste table par table + pièces) et **restauration vérifiée** dans un dossier distinct, nouveau profil.
- Page `/local` (dossiers sur ce PC, création, liens vers les feuilles) ; les écrans affichent le profil réel au lieu de « recette jetable » écrit en dur.
- Défaut antérieur corrigé : `DrizzleUploadQuotaStore.release` (rejeu d'une intention d'envoi FEC → 500). Migrations : inscription au registre atomique avec le fichier. Les recettes jetables refusent une base personnelle.
