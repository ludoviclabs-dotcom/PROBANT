Pièces synthétiques C12, dérivées de la fixture #70 (SYN-PACK18).

Les six CSV de base réutilisent exactement les formats livrés ; aucun nom/NIR ni donnée RH réelle. Les références et méthodes SYN sont fictives. Pour un dossier local, les méthodes de congés restent non établies sans inclusions/exclusions et règle applicable documentées.

Le script recette-c12.ts construit la variante qualifiée de congés à 1 000 / 1 100 et les variantes de paiement/déclaration. Leurs octets approuvés, empreintes et versions successives sont conservés dans PostgreSQL et dans l'export local. Les sources officielles sont distinctes : voir ../SOURCES.md.
